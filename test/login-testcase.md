# 高校教学档案管理系统（uni-archive-sys）阶段1：登录相关测试用例

- 测试范围：登录页展示与假登录跳转、路由守卫拦截、登录状态保持与退出
- 测试环境：前端分支 `feature-wang-qing-frontend`，本地启动访问 `http://localhost:5173`
- 前置说明：当前为模拟假登录，未对接后端接口与数据库，**账号、密码均非空即可登录成功**，不做真实账号校验
- 不涉及：真实账号校验、档案增删改等阶段2/3功能

---

## 一、正向场景

| 用例ID | TC-LOGIN-001 |
|---|---|
| 测试标题 | 输入非空账号和密码，登录成功并跳转档案页面 |
| 优先级 | P0 |
| 前置条件 | 前端服务已启动，访问 `http://localhost:5173` 可正常打开登录页；浏览器未登录（无登录态） |
| 操作步骤 | 1. 打开 `http://localhost:5173`，进入登录页；<br>2. 在账号输入框输入任意非空内容（如 `admin`）；<br>3. 在密码输入框输入任意非空内容（如 `123456`）；<br>4. 点击【登录】按钮 |
| 预期结果 | 1. 登录成功，无报错；<br>2. 页面跳转到档案列表页（URL 变为 `http://localhost:5173/archive`）；<br>3. 档案列表页正常展示，无白屏、无控制台报错 |
| 测试状态 | 待执行 |
